# 最凶UIかき氷注文システム

🍧 **#技育祭 特別企画** 🥶  
**『かき氷注文システムのUIを最凶にせよ！？』**

## 概要

ラムダ技術部（[@yoidea](https://twitter.com/yoidea), [@rossy_0213](https://twitter.com/rossy_0213)）も参加し、かき氷注文システムのUIをテーマにしたハッカソンのフロントエンドです。

## 更新情報

技術情報や詳細は随時更新予定です。

## 開発

以下のコマンドで開発サーバーを起動できます：

```bash
npm run dev
```

ブラウザで [http://localhost:3000](http://localhost:3000) を開いて結果を確認してください。
